# Typing Speed Test Chrome Extension

A modern, interactive Chrome extension to test your typing speed and accuracy. Features multiple difficulty levels, random challenges, and a beautiful, responsive UI that fills the entire new tab page.

## Features
- Full-page typing test (replaces Chrome's new tab page)
- Easy, Medium, and Hard typing challenges
- Randomized phrases for each difficulty
- Real-time feedback and results (WPM, accuracy, time)
- Modern, responsive design

## Installation

1. **Clone or Download the Repository**
   - Download this folder to your computer.

2. **Open Chrome Extensions Page**
   - Go to `chrome://extensions/`
   - Enable **Developer mode** (top right)

3. **Load the Extension**
   - Click **Load unpacked**
   - Select the `typing-speed-test-extension` folder

4. **Using the Extension**
   - Open a new tab (Ctrl+T or Cmd+T)
   - The Typing Speed Test will appear, filling the page
   - Select a difficulty, click "New Challenge", then "Start" to begin typing
   - View your results and try different challenges!

## Notes
- Only one extension can override the new tab page at a time. Disable other new tab extensions if needed.
- If you want to use the extension as a popup (by clicking the icon), let us know for alternate setup instructions.

## Customization
- Add more phrases to `page.js` for each difficulty level
- Adjust styles in `page.css` for a personalized look
